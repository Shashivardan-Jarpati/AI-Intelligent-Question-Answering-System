# AI Intelligent Question Answering System

## Project Overview
This project is an AI-based Question Answering System designed to respond to user queries using Natural Language Processing (NLP) techniques. The system retrieves the most relevant answer from a predefined knowledge base by applying text preprocessing, TF-IDF vectorization, and cosine similarity.

## Objectives
- Build an intelligent question answering system
- Demonstrate AI and NLP concepts
- Improve information retrieval from text data
- Provide accurate responses within a specific domain

## Technologies Used
- Artificial Intelligence
- Natural Language Processing (NLP)
- Python
- NLTK
- Scikit-learn

## How the System Works
1. User enters a question in natural language
2. Text is preprocessed (lowercasing, tokenization, stopword removal)
3. Knowledge base is vectorized using TF-IDF
4. Cosine similarity is applied to find the best match
5. The most relevant answer is displayed
