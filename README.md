# AI Intelligent Question Answering System

## Description
This project is a simple AI-based question answering system that uses Natural Language Processing to understand user questions and return relevant answers.

## Technologies Used
- Artificial Intelligence
- Natural Language Processing (NLP)
- Python
- TF-IDF
- Cosine Similarity

## How It Works
1. User enters a question
2. Text is preprocessed
3. AI matches question with knowledge base
4. Most relevant answer is displayed

## How to Run
pip install -r requirements.txt  
python main.py
